LITTLE STORY STEPS — FIVE-STORY PWA
Includes five illustrated stories, each with five scenes, questions, sentence models, sequencing and guided retelling.

RUN LOCALLY:
1. Unzip the folder.
2. Open Terminal in the unzipped folder.
3. Run: python3 -m http.server 8000
4. Open http://localhost:8000 in Chrome or Safari.

INSTALL:
Host the folder on an HTTPS static host (for example, GitHub Pages or Netlify).
Open the hosted URL on your phone. On iPhone/iPad: Share > Add to Home Screen.
On Android/desktop Chrome: use the Install app button or browser install option.

The app caches all story files for offline use after the first successful load.
Speech playback uses browser speech synthesis when available.
